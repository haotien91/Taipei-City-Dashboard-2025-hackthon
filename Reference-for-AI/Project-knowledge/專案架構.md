## 🏗️ 專案架構總覽

### 整體架構

```
台北城市儀表板 2025 Hackathon
├── 前端 (Taipei-City-Dashboard-FE) - Vue 3 + Vite
├── 後端 (Taipei-City-Dashboard-BE) - Go + Gin
```

## 💻 技術棧詳解

### 前端技術棧

- **核心框架**: Vue 3.4+ (Composition API)
- **構建工具**: Vite 5.0+
- **狀態管理**: Pinia 2.1+
- **路由**: Vue Router 4.2+
- **地圖引擎**:
  - Mapbox GL JS 3.1+
  - Deck.gl 9.0+ (3D 數據可視化)
  - Turf.js 6.5+ (地理空間分析)
  - Three.js + Threebox (3D 場景)
- **圖表庫**:
  - ApexCharts 3.45+ (主要圖表)
  - 自定義圖表組件
- **HTTP 客戶端**: Axios 1.6+
- **UI 工具**:
  - Material Icons
  - SCSS
  - dayjs (時間處理)

### 資料流架構

```
API 請求 → contentStore → 組件配置 + 圖表數據 → DashboardComponent → 圖表/地圖渲染
```

## 🔧 開發新 Dashboard Component 指南

### 需要修改的文件清單

#### 1. **後端 - 組件配置** (如有後端權限)

- 路徑: `Taipei-City-Dashboard-BE/`
- 新增組件配置到資料庫
- API: `POST /api/v1/component`

#### 2. **前端 - 組件定義**

- 路徑: `Taipei-City-Dashboard-FE/public/dashboards/backup_all_components.json`
- 新增組件配置：

```json
{
  "id": 新組件ID,
  "index": "unique_component_name",
  "name": "組件名稱",
  "source": "資料來源",
  "city": "taipei",
  "query_type": "time|two_d|three_d|percent|map_legend",
  "chart_config": {
    "types": ["BarChart", "DonutChart"],
    "color": ["#2e999b", "#80e3d4"],
    "unit": "單位",
    "categories": []
  },
  "map_config": null,
  "time_from": "current|static|month_ago",
  "time_to": "now",
  "update_freq": 10,
  "update_freq_unit": "minute",
  "short_desc": "簡短描述",
  "long_desc": "詳細描述",
  "use_case": "使用案例",
  "links": ["資料來源連結"],
  "contributors": ["貢獻者ID"]
}
```

#### 3. **前端 - 圖表組件** (如需新圖表類型)

- 路徑: `Taipei-City-Dashboard-FE/src/dashboardComponent/components/`
- 創建新的圖表組件 Vue 文件
- 模板結構：

```vue
<template>
  <div v-if="activeChart === 'YourChartName'">
    <apexchart
      :options="chartOptions"
      :series="parsedSeries"
      type="chart-type"
      height="300px"
    />
  </div>
</template>

<script setup>
import { computed, ref } from "vue";

const props = defineProps([
  "chart_config",
  "activeChart",
  "series",
  "map_config",
]);

const parsedSeries = computed(() => {
  // 資料處理邏輯
  return props.series;
});

const chartOptions = ref({
  chart: {
    /* 配置 */
  },
  colors: props.chart_config.color,
  // 其他 ApexCharts 配置
});
</script>
```

#### 4. **前端 - 註冊圖表類型**

- 路徑: `Taipei-City-Dashboard-FE/src/dashboardComponent/utilities/chartTypes.js`
- 新增圖表類型對應：

```javascript
export const chartTypes = {
  // ...existing types
  YourChartName: "您的圖表名稱",
};
```

#### 5. **前端 - DashboardComponent.vue**

- 路徑: `Taipei-City-Dashboard-FE/src/dashboardComponent/DashboardComponent.vue`
- 導入新組件並添加到組件列表

```javascript
import YourChartName from "./components/YourChartName.vue"

// 在 returnChartComponent 函數中添加
case "YourChartName":
  return svg ? YourChartNameSvg : YourChartName;
```

#### 6. **前端 - 資料處理** (如需特殊資料格式)

- 路徑: `Taipei-City-Dashboard-FE/src/dashboardComponent/utilities/`
- 創建或修改資料處理工具函數

## 🗺️ 開發新 Map Component 指南

### 需要修改的文件清單

#### 1. **地圖配置**

- 路徑: `Taipei-City-Dashboard-FE/src/assets/configs/mapbox/mapConfig.js`
- 新增地圖圖層樣式：

```javascript
export const maplayerCommonPaint = {
  // 新增地圖類型的 paint 屬性
  "your-map-type": {
    "circle-color": "#ff6b6b",
    "circle-radius": 8,
    "circle-opacity": 0.8,
  },
};

export const maplayerCommonLayout = {
  // 新增地圖類型的 layout 屬性
  "your-map-type": {
    visibility: "visible",
  },
};
```

#### 2. **組件配置中的地圖設定**

- 在組件配置中添加 `map_config`：

```json
"map_config": [
  {
    "index": "map_data_source",
    "type": "circle|fill|line|symbol|arc|voronoi|isoline",
    "title": "圖層名稱",
    "paint": {
      "circle-color": "#ff6b6b"
    },
    "property": [
      {"key": "name", "name": "名稱"},
      {"key": "value", "name": "數值"}
    ],
    "source": "geojson",
    "city": "taipei"
  }
]
```

#### 3. **地圖資料檔案**

- 路徑: `Taipei-City-Dashboard-FE/public/mapData/`
- 添加 GeoJSON 格式的地圖資料
- 檔名必須與 `map_config.index` 相同

#### 4. **地圖篩選功能** (可選)

- 在組件配置中添加 `map_filter`：

```json
"map_filter": {
  "mode": "byParam|byLayer",
  "byParam": {
    "xParam": "category",
    "yParam": "status"
  }
}
```

#### 5. **MapStore 修改** (如需特殊地圖功能)

- 路徑: `Taipei-City-Dashboard-FE/src/store/mapStore.js`
- 添加地圖控制方法

## 💡 開發建議與最佳實踐

### 1. 資料處理最佳實踐

```javascript
// ✅ 正確的資料格式
// 2D 資料
{
  "data": [{
    "data": [
      { "x": "類別1", "y": 100 },
      { "x": "類別2", "y": 200 }
    ]
  }]
}

// 3D 資料
{
  "categories": ["分類1", "分類2"],
  "data": [
    { "name": "系列1", "data": [10, 20] },
    { "name": "系列2", "data": [30, 40] }
  ]
}

// 時間資料
{
  "data": [{
    "name": "系列名稱",
    "data": [
      { "x": "2023-06-01T00:00:00+08:00", "y": 100 }
    ]
  }]
}
```

### 2. 組件開發流程

```mermaid
graph LR
    A[定義需求] --> B[設計資料結構]
    B --> C[創建組件配置]
    C --> D[開發圖表組件]
    D --> E[整合地圖圖層]
    E --> F[測試與優化]
```

### 3. 性能優化建議

- 使用 `v-if` 而非 `v-show` 控制圖表渲染
- 實施資料快取策略
- 使用 `computed` 處理複雜計算
- 避免在 `watch` 中執行重複請求

### 4. 錯誤處理

```javascript
try {
  const response = await http.get(`/component/${id}/chart`);
  // 處理成功響應
} catch (error) {
  console.error(`Failed to fetch data:`, error);
  // 設置默認值避免渲染錯誤
  this.chartData = [];
  // 通知用戶
  dialogStore.showNotification("error", "資料載入失敗");
}
```

### 關鍵技術要點

- 使用 Mapbox 熱力圖圖層
- 實施 WebSocket 即時資料更新
- 整合 TDX API 交通資料
- 使用 Turf.js 進行空間分析
