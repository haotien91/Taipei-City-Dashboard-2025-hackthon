# 🔒 商圈活化配置永久化解決方案

## 🎯 問題描述

**原問題**：每次系統啟動時都需要執行商圈活化腳本才能看到圖表和地圖功能。

**根本原因**：資料庫初始化文件 `dashboardmanager-demo.sql` 中包含 `TRUNCATE TABLE public.query_charts` 指令，每次系統初始化時會清空所有查詢圖表配置，包括商圈活化的設定。

## ✅ 解決方案

我們創建了包含商圈活化配置的**永久初始化SQL文件**，讓系統啟動時自動載入完整配置。

### 📁 創建的文件

1. **`db-sample-data/dashboardmanager-permanent.sql`** 
   - 包含完整商圈活化配置的永久初始化文件
   - 包含19個商圈配置項目和2個動態地圖配置

2. **`scripts/create-permanent-init.sh`**
   - 自動生成永久初始化文件的腳本
   - 匯出當前完整配置並創建新的初始化文件

3. **`scripts/switch-to-permanent-init.sh`**
   - 自動更新環境變數設定的腳本
   - 將 `MANAGER_SAMPLE_FILE` 切換到永久配置文件

4. **`scripts/test-permanent-solution.sh`**
   - 驗證永久化解決方案是否有效的測試腳本

## 🚀 使用方法

### 一鍵解決（已完成）
```bash
# 1. 生成永久配置文件
./scripts/create-permanent-init.sh

# 2. 切換到永久配置
./scripts/switch-to-permanent-init.sh

# 3. 驗證解決方案
./scripts/test-permanent-solution.sh
```

✅ **當前配置完整**: 2個儀表板 + 5個組件 + 2個動態地圖 + 3個查詢配置

- 🔄 **城市切換**: 支援雙北 ↔ 台北市資料切換

- 🔴 **紅色**: 剩3天結束的活動 (2個)
