# 🎨 市集活動動態地圖功能使用指南

## 📋 概述

市集活動動態地圖功能為台北城市儀表板添加了根據活動時間狀態自動變色的地圖圓點，讓用戶一眼就能了解活動的緊急程度和狀態。

## 🎨 動態顏色說明

| 顏色 | 狀態 | 描述 | 顏色代碼 |
|------|------|------|----------|
| 🔵 | 尚未開始 | 活動尚未開始 | #2196F3 |
| 🟢 | 正在進行 | 活動正在進行中 | #4CAF50 |
| 🟡 | 剩2週結束 | 活動剩2個禮拜結束 | #FFEB3B |
| 🟠 | 剩1週結束 | 活動剩1個禮拜結束 | #FF9800 |
| 🔴 | 剩3天結束 | 活動剩3天結束 | #F44336 |

## 🛠️ 腳本說明

### 1. 基礎腳本 (會覆蓋動態功能)
- `./scripts/setup-commercial-district.sh` - 台北商圈活化設置
- `./scripts/setup-commercial-district-metrotaipei.sh` - 雙北商圈活化設置

⚠️ **注意**：這些腳本會刪除並重新創建查詢配置，覆蓋動態地圖功能！

### 2. 恢復腳本 (保護動態功能)
- `./scripts/restore-dynamic-map-config.sh` - 恢復動態地圖配置

### 3. 包裝腳本 (自動保護)
- `./scripts/setup-commercial-district-with-dynamic.sh` - 台北版本 + 自動恢復動態功能
- `./scripts/setup-commercial-district-metrotaipei-with-dynamic.sh` - 雙北版本 + 自動恢復動態功能

## 🚀 推薦使用方式

### 方案 A：使用包裝腳本 (推薦)
```bash
# 台北版本 - 一鍵部署含動態保護
./scripts/setup-commercial-district-with-dynamic.sh

# 雙北版本 - 一鍵部署含動態保護  
./scripts/setup-commercial-district-metrotaipei-with-dynamic.sh
```

### 方案 B：手動執行 + 恢復
```bash
# 1. 執行基礎設置
./scripts/setup-commercial-district.sh

# 2. 恢復動態功能
./scripts/restore-dynamic-map-config.sh
```

## 🔄 工作流程

### 包裝腳本的工作流程：
1. **檢查腳本**：確認必要腳本存在
2. **執行基礎設置**：運行原始的商圈活化設置
3. **自動恢復動態功能**：立即恢復被覆蓋的動態地圖配置
4. **更新GeoJSON資料**：刷新活動狀態和顏色
5. **重啟後端服務**：確保配置生效
6. **驗證結果**：確認所有功能正常

## 🔧 問題排解

### 如果地圖點沒有顯示：
1. 檢查瀏覽器控制台是否有錯誤
2. 確認GeoJSON檔案存在且正確
3. 執行恢復腳本：`./scripts/restore-dynamic-map-config.sh`
4. 重啟後端服務：`docker restart dashboard-be`

### 如果顏色不正確：
1. 執行顏色更新：`python3 scripts/update_market_colors.py`
2. 檢查活動日期設定是否正確
3. 重新整理瀏覽器頁面

### 如果後端API異常：
```bash
# 檢查容器狀態
docker ps | grep dashboard-be

# 查看後端日誌
docker logs dashboard-be

# 重啟後端服務
docker restart dashboard-be
```
